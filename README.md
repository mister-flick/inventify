# Inventify

**IT asset management software for macOS.** An independent commercial project in active development.

## Official website

[Inventify](https://mister-flick.github.io/inventify/)

## Product

Inventify is being designed to help small and growing teams keep equipment records, lifecycle context, maintenance history, documents, reports and QR-coded labels together.

The public website describes the product's intended scope and development status. It does not present planned features as released functionality.

## AI development

An in-app assistant for natural-language questions about inventory is under consideration. Potential OpenAI sign-in and ChatGPT subscription access are being explored. No OpenAI integration or approval is in place, and no authentication or subscription flow is available.

Inventify is an independent project and is not affiliated with or endorsed by OpenAI.

## Project status

Inventify is in active development. This repository contains the public product website, not the private macOS application source.

GitHub Pages publishes the static site from the root of the main branch. The site uses HTML, CSS and JavaScript without a build step.
